# Indication-d-alarme-dans-le-contr-le-des-proc-d-s
Système d'alarme pour contrôle de procédé par API S7-300 : surveillance du remplissage et vidange, détection arrêt d'urgence et défauts d'ouverture/fermeture des vannes par temporisation de 5 s. Alarmes signalées par lampes rouges et buzzer réarmable via bouton RESET. Cycle verrouillé START/STOP.
